# 퇴근하기

큰 디지털 시계와 퇴근 버튼 하나로 만든 가벼운 브라우저 장난감.

- 누를 때마다 `+1` 애니메이션과 누적 횟수 표시
- 버튼을 누르고 놓을 때 입체적인 반동
- 한국 시간(Asia/Seoul) 매일 18:00:00 이상, 18:00:10 미만에 누르면 퇴근 완료
- 모바일 터치와 키보드 입력, 동작 줄이기 설정 지원

## 실행

`index.html`을 브라우저로 열면 됩니다. 설치와 빌드가 필요 없습니다.

HTML, CSS, Vanilla JavaScript만 사용합니다. 외부 라이브러리, 서버, DB가 없습니다.

## 파일

- `index.html`: 화면
- `style.css`: 스타일과 버튼
- `app.js`: 시계, 클릭 효과, 퇴근 시간 판정

## 동작

현재 시간은 기기의 시계를 한국 시간으로 변환해서 표시합니다. 클릭 횟수와 완료 상태는 현재 페이지에서만 유지되며 새로고침하면 초기화됩니다. 퇴근 시간은 `app.js`의 `isOpen()`에서 변경할 수 있습니다.

## 배포

세 파일을 그대로 정적 호스팅에 업로드하면 됩니다. GitHub Pages를 사용하는 경우 저장소 루트(`/`)를 게시 대상으로 지정하면 됩니다.
